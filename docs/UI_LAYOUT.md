# KS3 — схема интерфейса командного центра

## Цель

Главный экран должен полностью читаться в фиксированном окне **1440×900**. Пользователь не должен прокручивать первый экран, чтобы найти запуск матча, текущий ранг, отряд, операции или сезонную награду.

## Решения

- Левая панель: 260 px. В ней без прокрутки помещаются разделы «Операции», «Отряд», «Разведка», сезонный прогресс, настройки и профиль.
- Верхняя панель: 64 px. Она показывает название текущего раздела, регион, задержку, уведомления, настройки и профиль.
- Отступы основного экрана уменьшены до 24 px по горизонтали и 10 px по вертикали.
- Главный экран использует компактную иерархию: короткая строка состояния, hero-блок 230 px, три быстрые карточки и две нижние карточки с операциями и сезонным статусом.
- `ScrollContainer` оставлен для длинных разделов. При переходе на страницу вертикальная позиция сбрасывается в начало, поэтому пользователь не попадает в середину предыдущего экрана.
- Перенос строк у обычных подписей отключён. Перенос разрешён только там, где он задан явно через `\n`; это предотвращает сжатие элементов контейнеров до одной буквы в строке.
- Весь пользовательский текст интерфейса переведён на русский язык. Названия оружия, карт, игроков и технические сокращения (`RP`, `XP`, `FOV`, `HP`) сохранены как игровые обозначения.

## Проверка

Точка запуска остаётся прежней: `project.godot` → `scenes/main.tscn` → `scripts/main.gd`. В sandbox нет установленного бинарника Godot, поэтому окончательную проверку F5 нужно выполнить в Godot 4.5+ на рабочей машине.
