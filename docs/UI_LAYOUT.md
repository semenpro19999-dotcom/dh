# KS3 — схема интерфейса командного центра

## Цель

Главный экран рассчитан на базовый viewport **1440×900**, но окно можно свободно изменять. Godot автоматически масштабирует и расширяет интерфейс под фактический размер окна без обрезания. Пользователь не должен прокручивать первый экран, чтобы найти запуск матча, текущий ранг, отряд, операции или сезонную награду.

## Решения

- Левая панель: 260 px в базовом viewport. В ней без прокрутки помещаются разделы «Операции», «Отряд», «Разведка», сезонный прогресс, настройки и профиль.
- Верхняя панель: 64 px в базовом viewport. Она показывает название текущего раздела, регион, задержку, уведомления, настройки и профиль.
- Окно изменяемое: минимальный размер 800×500, stretch mode `canvas_items`, stretch aspect `expand`. При уменьшении весь интерфейс масштабируется равномерно, при увеличении получает дополнительное пространство.
- Отступы основного экрана уменьшены до 24 px по горизонтали и 10 px по вертикали.
- Главный экран использует компактную иерархию: короткая строка состояния, hero-блок 230 px, три быстрые карточки и две нижние карточки с операциями и сезонным статусом.
- `ScrollContainer` оставлен для длинных разделов. При переходе на страницу вертикальная позиция сбрасывается в начало, поэтому пользователь не попадает в середину предыдущего экрана.
- Перенос строк у обычных подписей отключён. Перенос разрешён только там, где он задан явно через `\n`; это предотвращает сжатие элементов контейнеров до одной буквы в строке.
- Весь пользовательский текст интерфейса переведён на русский язык. Названия оружия, карт, игроков и технические сокращения (`RP`, `XP`, `FOV`, `HP`) сохранены как игровые обозначения.

## Проверка

Точка запуска меню: `project.godot` → `scenes/main.tscn` → `scripts/main.gd`. Кнопки запускают `scenes/match.tscn` через `scripts/match.gd`. В sandbox нет установленного бинарника Godot, поэтому окончательную проверку F5 нужно выполнить в Godot 4.5+ на рабочей машине.
